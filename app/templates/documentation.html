Argus API Reference

The Argus API is organized around REST. All requests use standard HTTP methods and return JSON-encoded responses. The API standardizes municipal open data across Las Vegas, Los Angeles, Seattle, and Phoenix into unified data structures.

Base URL:
http://127.0.0.1:5000/api/v1

Authentication

Authenticate your API requests by including your secret API key in the X-API-Key request header or as a query parameter.

Header Format:
X-API-Key: {{ user_primary_key }}

Rate Limiting

Argus enforces a sliding-window rate limit depending on your plan tier. Rate limit headers are returned on all requests:

  • X-RateLimit-Limit: The request quota for the current 60-second window.
  • X-RateLimit-Remaining: The number of remaining requests allowed.
  • X-RateLimit-Reset: Seconds remaining until your quota resets.
GET

/api/v1/incidents

Retrieve standardized public safety, police, and emergency incident records across Las Vegas, LA, Seattle, and Phoenix.

Query Parameters

Param Type Description
city string Target municipality: las_vegas, los_angeles, seattle, phoenix, or all
category string Filter: Violent Crime, Property Crime, Traffic, Public Order
query string Keyword search across incident type and description
limit integer Number of results (1 to 100, default: 20)
GET

/api/v1/permits

Retrieve normalized residential and commercial construction, alteration, and solar permits across Las Vegas, LA, Seattle, and Phoenix.

Query Parameters

Param Type Description
city string Target municipality: las_vegas, los_angeles, seattle, phoenix, or all
permit_type string Filter: Residential, Commercial, Alteration, Solar
query string Search across permit description, applicant name, and address
limit integer Number of results (1 to 100, default: 20)
GET

/api/v1/businesses

Retrieve registered commercial establishments, active business licenses, and NAICS industry classifications.

Query Parameters

Param Type Description
city string Target municipality: las_vegas, los_angeles, seattle, phoenix, or all
category string Filter: Restaurant & Food, Retail, Professional Services, Healthcare
query string Search by business name or address
limit integer Number of results (1 to 100, default: 20)
GET

/api/v1/cities

Returns municipal connector metadata, open data portal endpoints, live upstream status, and dataset sync health.

GET

/api/v1/analytics/summary

Aggregated cross-city metrics including incident totals, city-by-city breakdowns, cache hit rates, and system uptime.

Errors & HTTP Codes

Argus uses conventional HTTP response codes to indicate API success or failure. Codes in the 2xx range indicate success, 4xx indicate client errors, and 5xx indicate gateway or upstream failures.

Code Status Description
200 OK Success The request succeeded and returned normalized data.
400 Bad Request Validation Error Invalid query parameters, limit out of range, or unknown city.
401 Unauthorized Authentication Error Missing or invalid X-API-Key header.
429 Too Many Requests Rate Limit Exceeded Request quota exceeded for the current window. Check X-RateLimit-Reset.
502 Bad Gateway Upstream Error The municipal open data portal is temporarily unreachable.
